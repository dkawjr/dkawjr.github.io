# Commonhour

A simple public product concept for transparent, specialty-aware residency scheduling.

The public page explains:

- what Commonhour does;
- how a program would adopt it in four steps;
- what residents, chief residents, and program directors would see;
- how the readable Rulebook and decision receipts avoid black-box scheduling.

This repository is a static GitHub Pages site. No information entered into the demo leaves the browser.

Commonhour is a provisional working name pending trademark and domain clearance. The concept does not guarantee ACGME compliance; final schedule review and compliance remain the program's responsibility.
