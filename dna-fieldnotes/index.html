    04 / Model selection

    What the model found.

    The model endpoint is a masked-token log-likelihood contrast. Clinical and trait associations are sourced independently.

    • NTv2 500M · run completedOpen weights, run locally. Scores for nine reported alleles appear below. Older than NTv3; no access wait.
    • AlphaGenome + AtlasOur preferred research option for effects on gene activity and RNA processing. Nine GRCh38 mappings and reference bases verified. API key pending.
    • NTv3A newer DNA foundation model for sequence and function. A local attempt was blocked by restricted model access.
    • Evo 2A modern general DNA model. Sequence model; not run in this report.
    • DNABERT-2An older, smaller sequence model; not run.
    Reading the score: negative means the alternate sequence is less expected than the reference; positive means more expected. Zero means equal preference. Units: natural-log probability difference (nats).

    Reproducible method, checks and limitations
    Adding AlphaGenome later

    AlphaGenome offers different outputs: predicted gene-regulation and RNA-processing effects. It has not been run here.

    1. Open the official API access page and sign in with Google.
    2. Review the terms and create a key if eligible.
    3. Keep the key local. It must never go in this public site or its GitHub repository.

    The source file uses GRCh37. All nine loci have passed reciprocal GRCh38 mapping and reference-base checks; the run is prepared.

    05 / Methods & coverage

    Methods & coverage.

    Input: selected array loci, not whole-genome sequencing. Calls have not been independently validated; no read depth, allele balance or probe-intensity data are available. Association evidence and assay validity are separate attributes.

    File quality and how this review was made
    Interpretation and endpoints

    Genotypes use GRCh37 genomic plus-strand notation. Transcript-oriented aliases are identified explicitly. Missing array loci are unmeasured.

    Literature effect sizes describe the specified study endpoint, population and genetic model. No personal absolute-risk model, ancestry calibration or comprehensive star-allele calling was performed.

    ClinVar classification, inheritance and review status are reported independently of array-call validity. Internal-probe matches retain variant-specific assay notes.

    NTv2 uses single-allele substitutions in reference context. Its 12 correlated views are token/strand sensitivity analyses; their range is not a confidence interval. Scores were not calibrated to clinical pathogenicity.
