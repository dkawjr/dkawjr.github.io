    04 / Model selection

    What the model found.

    Health information here comes from measured markers and published medical or trait evidence. A model’s prediction about a molecule is not the chance that you will develop a disease.

    • NTv2 500M · run completedOpen weights, run locally. Scores for nine reported alleles appear below. Older than NTv3; no access wait.
    • AlphaGenome + AtlasOur preferred research option for effects on gene activity and RNA processing. Current Atlas release: September 2026. Requires access and careful coordinate conversion.
    • NTv3A newer DNA foundation model for sequence and function. A local attempt was blocked by restricted model access.
    • Evo 2A modern general DNA model. A research alternative, not a personal medical interpreter.
    • DNABERT-2An older, smaller option. We did not choose it just to attach an AI label to this report.
    Reading the score: negative means the alternate sequence is less expected than the reference; positive means more expected. Zero means equal preference. These are log-probability differences, not disease probabilities.

    Reproducible method, checks and limitations
    Adding AlphaGenome later

    AlphaGenome offers different outputs: predicted gene-regulation and RNA-processing effects. It has not been run here.

    1. Open the official API access page and sign in with Google.
    2. Review the terms and create a key if eligible.
    3. Keep the key local. It must never go in this public site or its GitHub repository.

    The source file uses GRCh37. AlphaGenome requires validated GRCh38 mapping and reference-allele checks before a run.

    05 / Methods & coverage

    The file is a snapshot.

    Your file samples selected DNA positions. It is not a full genome sequence, and it does not measure your current health.

    File quality and how this review was made
    What “evidence” means here

    Measured: a letter pair in the raw file. A successful call is not a guarantee that it is correct.

    Published association: research or clinical guidance connecting a change to a trait or medicine. Strong evidence for an association does not validate this particular test result.

    Clinical confirmation: a suitable clinical test and interpretation. None of the raw calls in this review has been independently confirmed.

    AI prediction: a research estimate. NTv2 sequence-plausibility scores are included, with the model, method and per-view results. They are not clinical classifications.
